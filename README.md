# 🎮 Tic-Tac-Toe Game with Python and Tkinter

A simple and interactive **Tic-Tac-Toe game** developed using **Python** and the **Tkinter** library.

This project provides a graphical interface for playing the classic Tic-Tac-Toe game. Two players can take turns placing their symbols (**X** and **O**) on a 3×3 game board. The program automatically checks the board to determine the winner or whether the game ends in a draw.

---

## ✨ Features

* 🎮 Graphical Tic-Tac-Toe game
* 🖥️ User-friendly GUI built with Tkinter
* 👥 Two-player gameplay
* ❌ Player X

* 🏆 Automatic winner detection

## 🚀 How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

Check the Python version:

```bash
python --version
```

### 2. Run the Game

Open a terminal in the project directory and run:

```bash
python tic_tac_toe.py
```

The game window will open automatically.

---

## 🎮 How to Play

1. Start the application.
2. Player **X** makes the first move.
3. Click on an empty square to place your symbol.
4. Player **O** takes the next turn.
5. Players continue taking turns.
6. The first player to place three identical symbols in a row, column, or diagonal wins.
7. If all nine squares are filled without a winner, the game ends in a draw.
8. Start a new game to play again.
